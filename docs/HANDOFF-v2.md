## Deployment

The Vercel team free deployment quota was exhausted. The existing project has a promoted route serving the whole app from the isolated cloud runtime. Its older static gateway deployment metadata is distinct from the active source. Both /release.json and /health must match git HEAD after scripts/deploy-backend.mjs. No local tunnel or Mac service is involved.

Cloud service: espoo-common-ground on the authorised VPS, isolated Node 24 container, SQLite and static documents on persistent volumes. The key is transported through SSH stdin and retained only as host-bound encrypted ciphertext; decrypted directly into process memory. A public pilot still needs authenticated expiring invitations, encrypted origin transport and an AI Act assessment.

## Evidence and limits

STATUS.md has the measured table, API archive counts, review verdict, spec exceptions and taste-gate evidence. eval/v2/PROTOCOL.md describes the precommitted labels, splits, baselines and limits. The earlier stronger generic CV control remains archived. The data are scenario variants, so repeated runs are not independent populations or proof of real-world fairness.

Literal screenshot conflicts are documented: the overview’s stated height budget exceeds 900px, and mutually exclusive company tabs cannot show waiting and agreed meetings together. Fixed readable tokens and separate genuine captures are retained.
